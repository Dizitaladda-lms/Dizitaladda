📚 Curriculum

What Will You Learn?

A structured, project-driven curriculum covering front-end, back-end, and deployment.

  • Semantic HTML5 elements & accessibility
  • CSS Grid, Flexbox & responsive layouts
  • CSS Variables, custom properties & themes
  • Animations, transitions & micro-interactions
  • Tailwind CSS framework
  • Variables, data types & functions
  • DOM manipulation & event handling
  • Async/Await, Promises & Fetch API
  • ES6+ features: arrow functions, destructuring
  • Local storage & browser APIs
  • Component-based architecture & JSX
  • State management with hooks (useState, useEffect)
  • React Router for SPA navigation
  • Context API & Redux basics
  • Performance optimisation & best practices
  • Node.js runtime & npm ecosystem
  • Building REST APIs with Express.js
  • Middleware, routing & error handling
  • Authentication with JWT & bcrypt
  • File uploads & server security
  • NoSQL concepts & MongoDB CRUD
  • Mongoose ODM & schema design
  • Indexing, aggregation & optimisation
  • SQL basics with MySQL
  • Database design patterns
  • Connecting React frontend with Node backend
  • Full-stack CRUD applications
  • State management across stack layers
  • API versioning & documentation
  • Real-time features with Socket.io
  • Git workflow & GitHub collaboration
  • Deploying on Vercel, Netlify & Render
  • Environment variables & secrets management
  • CI/CD basics & GitHub Actions
  • Domain, SSL & production config
  • VS Code mastery & productivity extensions
  • Postman for API testing
  • Figma for design-to-code handoff
  • Integrating OpenAI & Gemini APIs
  • Building AI-powered web features
