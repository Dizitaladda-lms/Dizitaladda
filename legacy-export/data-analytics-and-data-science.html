📚 Curriculum

What Will You Learn?

A comprehensive journey from Excel basics to Machine Learning and AI-driven analytics.

  • Advanced Excel: PivotTables, VLOOKUP, Power Query
  • Data types, cleaning and formatting best practices
  • Statistical basics: mean, median, standard deviation
  • Conditional formatting and dashboard creation
  • Formulas for business analysis
  • SELECT, WHERE, JOIN, GROUP BY fundamentals
  • Subqueries, CTEs and window functions
  • Database design and indexing
  • SQL for business reporting
  • Practice with real business datasets
  • Power BI: data modelling, DAX and report publishing
  • Tableau: calculated fields, maps and story points
  • Interactive dashboard design principles
  • Connecting to databases, Excel and APIs
  • KPI tracking and business intelligence reports
  • Python basics: variables, loops, functions
  • Pandas for data manipulation and cleaning
  • NumPy for numerical analysis
  • Matplotlib & Seaborn for visualisation
  • EDA: exploratory data analysis projects
  • Descriptive vs inferential statistics
  • Hypothesis testing, p-values and confidence intervals
  • Correlation, regression and statistical significance
  • A/B testing methodology
  • Bayesian thinking basics
  • Supervised vs unsupervised learning
  • Linear and logistic regression
  • Decision trees, Random Forest, XGBoost
  • Model evaluation: accuracy, F1, AUC-ROC
  • Scikit-learn for model building
  • Neural network architecture basics
  • TensorFlow & Keras for model building
  • Natural Language Processing: sentiment analysis
  • Image classification and computer vision basics
  • Generative AI and LLM concepts
  • End-to-end data science project workflow
  • Deploying ML models with Flask & Streamlit
  • Google Colab, Jupyter and cloud environments
  • Building a complete data portfolio
  • Presenting insights to non-technical stakeholders
