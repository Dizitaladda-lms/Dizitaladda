Important Guidelines for Media Production

1. Always Use WebP

Export all web photos at 82–88% quality in WebP format. Cuts load size by 65%+ without visible compression artifacts.

2. Transparent Logos Only

Company logos and accreditation badges must have clean 100% transparent backgrounds (SVG or PNG-24).

3. Face Safe Area

On 4:5, 9:14, and 9:16 portrait cards, position the subject's face within the upper 55% area with 8–10% breathing room from the top.

4. Clean File Naming

Use lowercase hyphenated names only (e.g., kiran-bedi-award.webp, campus-classroom.webp).
